# lightspeed.trex.asset_replacements.core.shared

Shared asset replacement utilities for StageCraft, including skeleton remapping support and scoped skinned replacement
scale repair authored to the active non-session edit target. The shared core also validates and executes clipboard-based
light duplication by resolving mesh asset, descendant, and instance selections to their prototype asset roots. Successful
and failed copy and paste actions are reported to the console.
